# AutoHotkey Automation Scripts

Personal collection of lightweight AutoHotkey (AHK v1.1) utility scripts for input automation and ergonomic keybindings.

---

## Repository Structure

```text
autohotkey-scripts/
├── 2022-10-30_semi-to-auto_v01.ahk
└── README.md
```

---

## Scripts Inventory

| Script | Hotkey | Function |
| :--- | :--- | :--- |
| `2022-10-30_semi-to-auto_v01.ahk` | `F1` (Toggle Suspend) / `LButton` (Hold) | Converts semi-automatic mouse clicks into rapid automated repetitions while holding the left mouse button. Press `F1` to toggle script activation. |

---

## Execution & Compatibility

- **Interpreter:** AutoHotkey v1.1 (Windows).
- **Execution:** Run the `.ahk` script directly on Windows with AutoHotkey installed.
